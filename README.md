汉字笔画/部件测量与标注

## 运行

```bash
cd web
npm install

cd web
npm run dev

```

然后用浏览器打开终端输出的本地地址（默认 `http://127.0.0.1:5173/`）。

## 使用

- 支持**多个组**：每组可添加 **PNG** 和/或 **楷体拆出的笔画**（该组内按 OR 合并），多个组会再合并为**整体**。
- 左栏「笔画分组」：PNG 为 **700pt** 楷体拆出的 **800×800** 图，导入时整体右移 5%、下移 6%（40×48 px）；在线解析使用相同 700pt / 800×800；在各组点击笔画号或添加 PNG 混用。
- 默认会优先使用 **alpha 通道**生成 mask；若图片没有透明信息，会自动回退到亮度阈值二值化（可调阈值与反相）。
- 叠加显示：轮廓、外接框 bbox、主体框（默认 95%）、重心。可用“显示组标记”开关控制是否叠加每个组各自的标记；无论开关如何，都会绘制整体标记。
- 可导出：`metrics.json` 与当前画布的 `annotated.png`。

## 手动画图

右侧面板提供图示工具：笔画涂色（组内每个 PNG 为独立笔画）、直线/方框/方块、箭头、等距横竖图示、比例线段、双圆心扇形、十字标记、复制重心。支持选择拖拽、Delete 删除、Ctrl+Z/Y 撤销重做。导出 PNG 含手动画图与测量标记（不含田字格）。

## 字体笔画

与 PNG 共用同一套组与测量流程；字体图元栅格化为 512×512 透明 PNG（`十-stroke-0.png` 等）。字体文件：[`web/public/fonts/KaiTi_GB2312.ttf`](web/public/fonts/KaiTi_GB2312.ttf)（楷体许可请自行把握是否入库）。
