汉字笔画/部件测量与标注

## 运行

```bash
cd web
npm install
npm run dev
```

然后用浏览器打开终端输出的本地地址（默认 `http://127.0.0.1:5173/`）。

## 使用

- 支持**多个组**：每个组选择 1~n 张 PNG（该组内合并），多个组会再合并为**整体**（都按 OR 合并，重叠像素只算一次）。
- 默认会优先使用 **alpha 通道**生成 mask；若图片没有透明信息，会自动回退到亮度阈值二值化（可调阈值与反相）。
- 叠加显示：轮廓、外接框 bbox、主体框（默认 95%）、重心。可用“显示组标记”开关控制是否叠加每个组各自的标记；无论开关如何，都会绘制整体标记。
- 可导出：`metrics.json` 与当前画布的 `annotated.png`。
